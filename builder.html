Retro 108 Rule Picker

All twenty-two rules, switched on. Turn off anything you do not want, change the ones whose output is a matter of taste, and give any of those a second action on hold. The file assembles below in the original order, which matters — a broad rule above a narrow one hides it. Nothing leaves this page.

Highlighted keys are the ones your current selection changes.

Super Buttons

The board's own pair, plus up to eight more through the four 3.5mm jacks on the back — two to ten buttons that this rule set otherwise ignores entirely. All of this is tested on hardware: a programmed Super Button emits its recorded combination where Karabiner can see it, accepts modifiers on top, sustains a hold, and chords with another Super Button.

Record onto each button with ★ (Fast Key Mapping): press ★, then left_shift + right_shift + the key below, then the Super Button. Both shifts are deliberate — this rule set never swaps either one, macOS claims neither, and nobody presses both by accident.
